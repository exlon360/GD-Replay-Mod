# v0.2.0

- Changed the creator identity to xVionGD and the mod ID to `xviongd.replay-mod`.
- Moved the purple Replay entry point to the level selection and level info screens, before normal gameplay starts.
- Added a dedicated viewer for watching the latest compatible replay.
- Scoped attempt search and selection to the currently selected level.
- Limited pause, speed, and hitbox controls to watched replay sessions.
- Added a frozen death-frame state for paused footage of a failed attempt.

- Added safe playback from the beginning of the current level.

- Added pause, resume, and playback speed presets.
- Added debug hitbox toggle.
- Added purple cover artwork.
